# Superheros Project

## Description
Manage superheros data and communication with base.
allow to send a delayed message to base, which will be persisted and triggered when the time comes.

## Installation
To install the project, follow these steps:
1. Clone the repository:
    ```bash
    git clone https://github.com/shacharbuda/superheroes.git
    ```
2. Navigate to the project directory:
    ```bash
    cd superheroes
    ```
3. Install the dependencies:
    ```bash
    npm install
    ```

## Usage
To start the application, run:
```bash
npm start
```
Open your browser and navigate to `http://localhost:3000` to view the application.

## Features
- Add or see superhero data.
- Send new message by superhero with delayed time.
